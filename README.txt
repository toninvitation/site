TONInvitation — versão preparada para automatização

Ficheiros:
- index.html
- style.css
- script.js
- templates.js

A pasta Images deve continuar a existir ao lado destes ficheiros.

O que esta versão já faz:
1. Catálogo com filtros.
2. Modelos definidos num ficheiro separado (templates.js).
3. Botão "Personalizar" em cada modelo.
4. Janela de personalização.
5. Campos de nome, data, hora, local e e-mail.
6. Escolha de várias cores por modelo.
7. Pré-visualização em tempo real.
8. Menu mobile.
9. Carrossel de avaliações.

Importante:
Esta é a camada FRONT-END. O botão "Simular pedido" ainda não envia dinheiro, não guarda pedidos e não envia e-mails. Essa parte precisa de backend/serviço de automação.

Próxima fase recomendada:
- ligar o formulário a uma base de dados;
- adicionar pagamento;
- gerar automaticamente o convite final;
- enviar o ficheiro/link por e-mail;
- criar uma página/URL própria para cada convite, se quiseres convites interativos.
