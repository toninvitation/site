# TONInvitation — 4 idiomas

Idiomas:
- 🇵🇹 Português
- 🇬🇧 English
- 🇫🇷 Français
- 🇪🇸 Español

Ficheiros incluídos:
- index.html
- categoria.html
- modelos.html
- categoria.js
- modelos.js
- style.css
- i18n.js

O `i18n.js` é o sistema central de traduções.
O idioma escolhido fica guardado no navegador.

As imagens e a estrutura dos convites não são alteradas.
Os textos que fazem parte da própria arte do convite continuam a ser
conteúdo personalizável e não são traduzidos automaticamente.
